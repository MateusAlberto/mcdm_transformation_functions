# MCDM Transformation Functions & Simulation Analysis

This repository contains Google Colab notebooks supporting research on evaluating bias and domain displacement introduced by transformation functions in Multi-Criteria Decision-Making (MCDM) models based on Non-Reciprocal Fuzzy Preference Relations (NRFPR) and Orlovsky's decision-making techniques.

## Notebooks

| Notebook | Colab Link | Description |
| :--- | :---: | :--- |
| **Transformation Functions**<br>`Transformation_Fuctions.ipynb` | [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MateusAlberto/mcdm_transformation_functions/blob/main/Transformation_Fuctions.ipynb) | Implements transformation functions from different preference formats (rankings, utility vectors, multiplicative and fuzzy preference relations) into NRFPRs, alongside Orlovsky aggregation and choice techniques. |
| **Simulation Analysis**<br>`Simulation_Analysis.ipynb` | [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MateusAlberto/mcdm_transformation_functions/blob/main/Simulation_Analysis.ipynb) | Implements the Monte Carlo simulation framework, convergence stability analysis (up to 100,000 iterations), bootstrap confidence intervals, run-to-run stability tests, and criterion contribution analysis. |

## Usage

Click the **Open in Colab** badges above to run and reproduce the experiments directly in Google Colab without local setup.
